# Cartiva - AI Coding Instructions

## Project Goal

Build a modern, responsive e-commerce frontend called Cartiva.

## Technology

* Use HTML, CSS, and JavaScript.
* Use React when the project setup is ready.
* Use Git and GitHub for version control.

## Coding Conventions

* Write readable, beginner-friendly code.
* Use clear and descriptive variable and component names.
* Keep components small and reusable.
* Use consistent formatting and meaningful file names.

## Design Guidelines

* Create a clean, modern shopping interface.
* Ensure responsive layouts for mobile and desktop.
* Use accessible colors, labels, and buttons.

## Development Rules

* Understand the existing code before changing it.
* Avoid unnecessary dependencies.
* Explain significant changes clearly.
* Test changes when possible.
* Never expose API keys, passwords, or secrets.
