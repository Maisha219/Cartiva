# Cartiva

A modern and responsive e-commerce web application.

## Overview

Cartiva is a frontend-focused online shopping experience designed to make browsing products and managing a shopping cart simple and convenient.

## Planned Features

* Responsive homepage and product catalog
* Product search, filtering, and sorting
* Shopping cart and wishlist
* Product details
* Demo checkout experience
* AI-powered shopping assistance (planned)

## Technology Stack

* HTML, CSS, JavaScript
* React (planned)
* Git and GitHub

## Project Status

Currently in the initial setup phase.
